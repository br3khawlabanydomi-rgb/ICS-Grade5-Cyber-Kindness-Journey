# ICS Grade 5 — Stop Cyberbullying Adventure

A standalone interactive walking-map game for Grade 5. Includes six cyber safety and AI missions, 120 points, collectible stickers, supportive feedback, and a printable personalized certificate.

## Publish on GitHub Pages
1. Create a new **public** repository named `ICS-Grade5-Cyber-Kindness-Journey`.
2. Upload `index.html`, `README.md`, and `.nojekyll` to the repository root (not a nested folder).
3. Open **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, and save.
4. After deployment, visit `https://YOUR-USERNAME.github.io/ICS-Grade5-Cyber-Kindness-Journey/`.

No login, external scripts, or server are required. Student names stay within the browser tab and are not stored or transmitted. Certificates can be printed or saved as PDF via the browser's print dialog.
